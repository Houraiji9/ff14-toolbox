# FF14工具箱

面向《最终幻想 XIV》国服玩家的 Windows 桌面工具，整合价格查询、批量查价、带货查询、压价监控、低价监控、市场统计、成本计算与招募查询。

## 下载

请从 [GitHub Releases](https://github.com/Houraiji9/ff14-toolbox/releases/latest) 下载最新的 `FF14Toolbox_v版本号.zip`。

解压完整文件夹后运行 `FF14工具箱.exe`。程序内的“设置 → 检查程序更新”可手动检查正式发布版本；本地数据、配置、日志和缓存会在更新时保留。

## 数据来源

- 游戏基础资料：[thewakingsands/ffxiv-datamining-cn](https://github.com/thewakingsands/ffxiv-datamining-cn)
- 市场价格与成交数据：[Universalis](https://universalis.app/)
- 招募信息：公开招募数据服务
