# FF14工具箱

面向《最终幻想 XIV》国服玩家的非官方 Windows 桌面工具，将常用市场与制作查询集中在一个程序中。

当前公开版本：**v4.16.0（首次公开发布）**

## 下载与运行

请从 [GitHub Releases](https://github.com/Houraiji9/ff14-toolbox/releases/latest) 下载 `FF14Toolbox_v4.16.0.zip`。

1. 完整解压压缩包，不要只从压缩软件内直接运行。
2. 打开 `FF14工具箱` 文件夹，运行 `FF14工具箱.exe`。
3. 后续可在“设置 → 检查程序更新”中手动检查正式版本。

程序更新会保留本地的数据、配置、日志和缓存文件。建议更新前正常退出正在运行的工具箱。

## 功能

- **价格查询**：查看国服各服务器在售、成交、均价与 NPC 金币商店信息。
- **批量查价**：批量查询多个道具，比较价格并生成采购方案。
- **带货查询**：结合雇员委派、市场价格和销量筛选带货收益。
- **压价监控**：监控自己的雇员挂单及被压价情况。
- **低价监控**：按独立价格线或四日均价比例定时发现低价挂单。
- **市场统计**：按物品分类、生产制作、部队工房、商店、兑换和雇员来源统计行情。
- **成本计算**：比较市场采购、NPC 购买、继续制作与部队工房方案，计算成本、利润和时薪。
- **招募查询**：筛选国服公开招募并支持关键词提醒。

## 数据与隐私

- 游戏基础资料和可下载数据保存在程序目录的 `程序运行文件/数据文件`。
- 用户设置保存在 `程序运行文件/配置文件`，日志和缓存分别存放在对应文件夹。
- 工具不会修改游戏客户端，也不会自动执行游戏内操作。
